# OTPGuard repository instructions

Before modifying this repository, read [HANDOFF.md](HANDOFF.md) completely and follow
its design references. For implementation or PR review revisions, also read
[CODEX_PR_WORKFLOW.md](CODEX_PR_WORKFLOW.md) and the selected PR in
[docs/implementation-plan.md](docs/implementation-plan.md).

Work on one user-requested PR at a time. Present its validation and acceptance results,
then stop for review. Repository plans and prompt templates are reference material;
they do not authorize starting features, creating chats, publishing, merging, or deploying.
